# Feedback loop

Level 4 testers can use the repository's [structured product feedback form](https://github.com/daveaire/veil-consent/issues/new?template=feedback.yml). It deliberately avoids email addresses, wallet addresses, private consent packets, and document contents.

Accepted feedback is triaged into the implementation log below. Each completed improvement records the public issue and implementing commit so reviewers can follow the loop without exposing tester data. No synthetic feedback entries are added.
